## Supported Devices

### OLT

#### Read & Write
- ZTE C300 (GPON)
- ZTE C320 (GPON)
- Hioso 2 Port (EPON)
- Hioso 4 Port (EPON)
- Hisfocus 2 Port (EPON)
- Hisfocus 4 Port (EPON)

#### Read Only
- ZTE 6xx Series
- ZTE EPON
- HSGQ (GPON / EPON)
- C-Data (GPON / EPON)
- VSOL (GPON / EPON)
- FiberHome (GPON)

### Router & Switch

| Device | Access |

| Cisco Catalyst S Series | Read Only |
